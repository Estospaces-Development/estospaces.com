# Blog Ranking Protocol

No system can guarantee rank 1 in Google or GPT/AI answers. This protocol maximizes crawlability, usefulness, trust and answer-engine extractability, but rankings still depend on competition, backlinks, user satisfaction, technical health, freshness and search-engine systems outside Estospaces control.

## A. Topic Selection

- Map every topic to one search intent: informational, commercial, navigational or transactional.
- Define the primary keyword, secondary keywords, entities and related questions before writing.
- Avoid cannibalization by checking whether another post already targets the same reader, keyword and intent.
- Prefer people-first topics with a real decision, risk, deadline, checklist, calculator, template or local comparison.
- Use the canonical source folder `../docs/blog-posts-to-do` for the initial topic map.

## B. Content Brief

Each post must define:

- target reader
- reader pain point
- promise of the article
- primary keyword
- related entities
- suggested title
- meta title
- meta description
- H2/H3 outline
- FAQ questions
- image concept
- internal links
- external authoritative references

## C. Content Quality

Each article must:

- answer the main query early
- include original insight, examples, checklists, templates or frameworks
- include practical steps
- include expert review notes where possible
- disclose AI assistance if the site adopts an AI disclosure policy
- be edited for accuracy and usefulness
- avoid mass-produced generic content
- avoid unsupported statistics
- cite primary sources for legal, tax, safety and market claims

## D. Technical SEO Checklist

- indexable page
- canonical URL
- sitemap inclusion
- valid structured data
- optimized title and meta description
- Open Graph and Twitter/X tags
- image alt text
- responsive images with width and height
- fast loading and no layout shift
- no broken links
- no duplicate slug, title or meta description
- internal links added
- updated date shown

## E. AI/GPT Visibility Checklist

- concise answer block
- key takeaways
- entity-rich headings
- FAQ
- comparison table if relevant
- cited factual claims
- author, published date and updated date metadata
- schema markup
- clear definitions
- original examples
- no fluff

## F. Publishing Workflow

1. Draft.
2. Editorial review.
3. Factual review.
4. SEO review.
5. Image review.
6. Publish.
7. Submit sitemap.
8. Monitor Search Console.
9. Refresh after 30, 60 and 90 days based on performance.

## Repeatable Post Template

Use this structure for every production post:

1. Title with jurisdiction, date or asset when relevant.
2. Direct answer in the first 100 to 150 words.
3. Key takeaways.
4. Definitions for important terms.
5. Step-by-step process.
6. Comparison table or decision matrix.
7. Practical checklist or downloadable asset.
8. Estospaces workflow and internal links.
9. FAQ.
10. Sources and references.

## Review Rule

If a post affects money, housing, legal rights, tax or safety, do not publish it from generated text alone. It needs human factual review against the cited primary sources before promotion.
